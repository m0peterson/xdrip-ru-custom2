# xDrip+ RU custom — Libre 2 RU через Juggluco, с калибровкой в xDrip

Модификация [xDrip+](https://github.com/NightscoutFoundation/xDrip) для Android. Целевой сценарий — получать показания **FreeStyle Libre 2 российского региона**, которые уже читает Juggluco, и добавлять к ним калибровку по глюкометру в xDrip.

**Это не самостоятельный драйвер RU-сенсора.** Распознавание Libre 2 Gen2 по NFC не означает возможность его расшифровать или подключить напрямую. Если Juggluco не получает показания от конкретного сенсора, эта сборка xDrip проблему подключения не решит.

```text
Libre 2 RU → NFC / Bluetooth → Juggluco
                                 │ Patched Libre broadcast, локально на телефоне
                                 ▼
                       xDrip: Libre2 Patched
                                 │ калибровка по глюкометру
                                 ▼
                      график, тревоги, выгрузка
```

## С чего начать

1. Прочитайте [пошаговую настройку телефона, Juggluco и калибровок](docs/GUIDE.md).
2. Если собираете приложение сами — [установка среды, сборка APK и тесты](docs/INSTALL-AND-SETUP.md).
3. Результаты текущей проверки и ограничения — [отчёт проверки](docs/CURRENT-VERIFICATION.md). [Старый отчёт](docs/verification-report.md) относится к версии `718d082` и не подтверждает текущую сборку.

## Краткий порядок настройки

1. Сохраните БД и настройки прежнего xDrip **до установки или удаления приложения**. Установите APK этой модификации; при несовпадающей подписи потребуется миграция по [руководству](docs/GUIDE.md#2-резервная-копия-и-установка-xdrip).
2. Подключите сенсор к Juggluco и убедитесь, что в нём регулярно появляются свежие значения по Bluetooth.
3. В Juggluco включите **Patched Libre broadcast**, получатель — `com.eveningoutpost.dexdrip`. Собственную активную калибровку выходных данных Juggluco оставьте выключенной, если корректировать будете в xDrip.
4. В xDrip выберите источник **Libre2 Patched** и нужные единицы. Разрешите фоновую работу обоих приложений и дождитесь нескольких новых точек.
5. В настройке **Калибровка Libre / OOP2** оставьте `Calibrate based on raw` (или `Calibrate based on glucose`). Затем меню → **Добавить калибровку** → значение глюкометра в выбранных единицах.
6. Проверьте следующее новое показание, работу с выключенным экраном и тревоги. `No calibration` отключает поправку для новых точек, но не отменяет уже изменённую историю.

Развёрнутые инструкции, замена сенсора и диагностика — в [GUIDE.md](docs/GUIDE.md).

## Что есть в этой модификации

| Возможность | Поведение |
|---|---|
| RU / Gen2 распознавание | Семейства patchInfo `0x2B`, `0x2C`, `0x76` выделены в `Libre2Gen2`; прямое NFC-чтение прекращается с подсказкой об использовании моста |
| Приём от Juggluco | Источник `Libre2 Patched`, внутреннее имя `LibreReceiver`; получает протокол Patched Libre |
| Калибровка | Пункт «Добавить калибровку» для поддерживаемых Libre-источников; для `Libre2 Patched` поправка только смещением |
| Границы поправки | Наклон `1`, смещение от **−40 до +20 mg/dL** (примерно −2,2…+1,1 ммоль/л); это не произвольная подгонка показаний |
| Текущие значения и история протокола | Калибровка применяется при вставке новых данных; одинаковые или близкие временные метки отсекаются |
| «No calibration» | Новые значения сохраняются без поправки, даже если в БД осталась старая калибровка; старый график автоматически не восстанавливается |

xDrip получает уже рассчитанную глюкозу, а не электрические «сырые» данные сенсора. Калибровка в xDrip — дополнительная обработка этих значений. Не включайте одновременно активную калибровку в Juggluco, если хотите оценивать только поправку xDrip.

## Совместимость и границы

- Нужны Android-телефон, совместимая с конкретным сенсором версия Juggluco и работающий поток в самом Juggluco. Для Gen2 практический ориентир — Android 8 или новее; требования Juggluco проверяйте на его сайте.
- Прямой путь Libre 2 EU/OOP2 — отдельный сценарий; данная инструкция описывает RU → Juggluco → `Libre2 Patched`.
- OOP2 не добавляет в xDrip поддержку расшифровки Gen2. Не устанавливайте его как способ починить RU-подключение.
- Передача с телефона на часы — функция xDrip; самостоятельное чтение RU Gen2 часами эта модификация не реализует.
- Работа с настоящим сенсором, конкретным телефоном, тревогами и внешними системами требует отдельной проверки на устройстве. Автотесты не заменяют такую проверку.

## Установка и обновление

APK для проверки доступен в [предварительном релизе `ru-custom-dev-2026.11.03`](https://github.com/m0peterson/xdrip-ru-custom2/releases/tag/ru-custom-dev-2026.11.03). Это вариант `prodDev` со всеми переводами и **debug-подписью**, а не стабильный release. В релизе приложены `SHA256SUMS` и сводка тестов. Для самостоятельной сборки используйте [инструкцию разработчика](docs/INSTALL-AND-SETUP.md).

Идентификатор приложения — `com.eveningoutpost.dexdrip`. Обновление поверх установленного xDrip возможно только при совпадении подписи. **До любого удаления приложения экспортируйте БД и настройки и скопируйте резервную копию с телефона.** Порядок миграции описан в [руководстве](docs/GUIDE.md#2-резервная-копия-и-установка-xdrip).

Не включайте обновление из стандартного канала xDrip, если хотите сохранить эту модификацию: внешний APK может иметь другую подпись или не содержать её изменений.

Код распространяется по GPLv3, как xDrip+. Juggluco — отдельный проект со своей лицензией. Проект не связан с Abbott. Это DIY-приложение; при несоответствии самочувствию проверяйте глюкозу глюкометром и следуйте согласованным с врачом правилам действий.
