# Настройка Libre 2 RU → Juggluco → xDrip+ RU custom

Руководство для **FreeStyle Libre 2 российского региона**, включая распознаваемые xDrip семейства Gen2. Название приложения — xDrip+, название сенсора — FreeStyle Libre 2: отдельного сенсора «xDrip2» нет.

Цель настройки: сначала получить свежие значения в Juggluco, затем увидеть их в xDrip и только после этого включать калибровку. Названия пунктов приведены на русском и английском; перевод и расположение меню зависят от версии приложения.

## 1. Что подготовить

- Телефон с NFC и Bluetooth, совместимый с вашим сенсором и Juggluco. Для Gen2 ориентируйтесь на Android 8+ и актуальные требования Juggluco.
- Активированный сенсор. Активация, прогрев и поддержка региона — задача приложения, читающего сенсор; xDrip в этой схеме сенсор не активирует.
- Juggluco из [официального источника](https://www.juggluco.nl/Juggluco/download.html). Проверьте поддержку именно вашей модели/региона; сам факт наличия «Libre 2» на коробке недостаточен.
- APK этой модификации, соответствующий нужной версии исходников, либо [среду для сборки](INSTALL-AND-SETUP.md).
- Глюкометр и тест-полоски для проверки и, при необходимости, калибровки.

Не передавайте пароли, токены Nightscout, резервную БД или серийный номер сенсора в открытые обсуждения. Для диагностики обычно достаточно версии приложений, выбранного источника и фрагмента журнала без личных данных.

## 2. Резервная копия и установка xDrip

1. В старом xDrip откройте меню экспорта/импорта и экспортируйте БД. Отдельно сохраните настройки, если используете их экспорт.
2. Найдите созданные файлы и скопируйте их на компьютер или в другое надёжное место. Убедитесь, что файлы читаются и имеют ненулевой размер. После удаления приложения его внутренние данные могут исчезнуть.
3. Запишите версии старого xDrip и Juggluco, источник данных, единицы, настройки тревог и выгрузки. Снимки экранов могут содержать личные данные — храните их приватно.
4. Попробуйте установить новый APK поверх старого. Если подпись совпадает, Android предложит обновление с сохранением данных.
5. Если Android сообщает о конфликте пакета/подписи, ещё раз проверьте резервные копии. Только затем удаляйте прежний xDrip и устанавливайте новый APK. Менять подпись уже установленного приложения без удаления Android не позволяет.
6. Разрешите установку из выбранного источника только тому файловому менеджеру или браузеру, через который устанавливаете APK.
7. Откройте xDrip и завершите начальные экраны. При миграции импортируйте БД через соответствующий пункт меню, дождитесь окончания и проверьте историю. Затем проверьте источник данных: импорт может вернуть старое значение настройки.
8. Проверьте версию в сведениях о приложении. Старый APK `718d082-ru-custom-2026.09.16` не содержит более поздних исправлений из этого репозитория.

## 3. Разрешения и фоновая работа

Для **Juggluco и xDrip**:

1. Разрешите уведомления, если Android запрашивает их.
2. В системных настройках батареи разрешите работу без ограничений. На телефонах с отдельным «автозапуском» разрешите и его.
3. Не используйте «Принудительно остановить»: после этого Android может не доставлять сообщения до ручного запуска приложения.
4. Оставьте приложения установленными в одном пользовательском профиле Android. Передача между личным и рабочим профилем может блокироваться.

Для **Juggluco**, которое читает сенсор:

5. Разрешите «Устройства поблизости» / Bluetooth. На старых версиях Android для поиска BLE может требоваться геолокация и разрешение на неё — ориентируйтесь на запрос самого Juggluco.
6. Включите NFC на время сканирования и Bluetooth для постоянного получения значений.

xDrip в выбранной схеме получает локальные сообщения от Juggluco; сопрягать сенсор с xDrip в меню Bluetooth не нужно. Интернет для локальной передачи между двумя приложениями не нужен. Выгрузка в Nightscout и другие сетевые функции требуют отдельного подключения.

## 4. Сначала добейтесь показаний в Juggluco

1. Проверьте модель и регион сенсора. Следуйте инструкции Juggluco для этой модели по активации. Для типов, требующих первичной активации Abbott-приложением или считывателем, выполните её там. Не запускайте повторную активацию уже работающего сенсора по инструкции для другой модели.
2. Откройте Juggluco и отсканируйте сенсор по NFC. Удерживайте телефон до подтверждения считывания.
3. Дождитесь конца прогрева, если сенсор новый.
4. Проверьте Bluetooth-приём: в Juggluco должны появляться **новые** значения с обновляющимся временем, а не только история, полученная NFC-сканом.
5. Если другое приложение Abbott перехватывает соединение, используйте рекомендации Juggluco по освобождению Bluetooth-соединения. При необходимости ограничьте Bluetooth-разрешение конкурирующего приложения. Это может отключить его тревоги и передачу в LibreView — сначала убедитесь, что остаётся рабочий способ контроля.
6. Если свежего потока в Juggluco нет, остановитесь на диагностике Juggluco/сенсора. Смена настроек калибровки xDrip этот этап не исправляет.

**Контрольная точка:** Juggluco показывает несколько последовательных свежих значений и время их получения меняется.

## 5. Включите передачу из Juggluco

1. В Juggluco откройте левое меню → **Settings / Настройки**. В зависимости от версии настройки трансляций могут находиться в разделе обмена данными.
2. Найдите **Patched Libre broadcast** и включите его.
3. Если приложение предлагает выбрать получателя, выберите xDrip. Если запрашивает application ID / имя пакета, укажите точно:

   ```text
   com.eveningoutpost.dexdrip
   ```

4. Сохраните настройку и вернитесь к графику. Дождитесь следующего нового значения.
5. Для этой схемы не выбирайте вместо него **xDrip broadcast**: это другой протокол, который, например, используют получатели данных от xDrip. Также не заменяйте его Eversense/Glucodata, оставляя источник `Libre2 Patched` в xDrip.
6. В современных версиях Juggluco есть собственная калибровка. Если калибровать будете в xDrip, оставьте применение калибровки к выходным данным Juggluco выключенным. Иначе xDrip будет корректировать уже скорректированное значение.

Первичный источник: [описание Juggluco, раздел Other apps](https://www.juggluco.nl/Juggluco/). Версия Juggluco может менять расположение элементов, поэтому используйте встроенную Help рядом с настройкой.

## 6. Настройте источник в xDrip

1. Откройте **Настройки → Источник данных / Hardware data source**.
2. Выберите **Libre2 Patched** (в мастере настройки он может быть внутри группы Libre). Внутреннее имя настройки — `LibreReceiver`; это полезно при чтении журналов.
3. Выберите единицы: **ммоль/л** либо **mg/dL**. Проверьте единицы на главном экране до ввода значений с глюкометра.
4. Вернитесь на главный экран и дождитесь данных. При получении потока xDrip создаёт локальную запись сенсора, если её ещё нет. Это запись в БД, а не активация физического сенсора.
5. Если мастер просит зарегистрировать сенсор, используйте **Start sensor / Запустить сенсор**, укажите реальное время или ответ **Not today / Не сегодня** для уже работающего сенсора. Не пытайтесь запустить RU Gen2 прямым NFC-сканом в xDrip.
6. Подождите до нескольких циклов приёма. По умолчанию мост присылает минутные значения, а xDrip сохраняет точки реже (обычно примерно раз в пять минут) и сглаживает их. Поэтому цифры двух приложений не обязаны совпадать в каждую минуту.
7. Проверьте **Состояние системы / System Status** и карточку Libre2: есть время последнего входящего значения. Убедитесь, что время на главном графике тоже обновляется.

**Контрольная точка:** новые показания появились в xDrip и продолжают поступать, пока экран телефона выключен. До калибровки данные должны отображаться без требования двух начальных калибровок.

Обычный Patched Libre поток Juggluco передаёт текущие значения. Поддержка исторических сообщений в xDrip не означает, что Juggluco автоматически восстановит все пропуски этим протоколом.

## 7. Включение и ввод калибровки

### 7.1. Режим

1. Откройте **Настройки → Расширенные / дополнительные настройки xDrip+ → Менее распространённые настройки / Less Common Settings → Другие разные параметры / Other misc options**. В разных переводах название может отличаться; можно воспользоваться поиском настроек.
2. Найдите **Калибровка Libre / OOP2 / Libre / OOP2 calibration** (старое название — «Калибровка по алгоритму OOP2»).
3. Выберите **Calibrate based on raw** — штатное значение по умолчанию. Для `Libre2 Patched` значения уже в единицах глюкозы, и этот режим включает поправку xDrip. **Calibrate based on glucose (experimental)** также включает её для моста; различие режимов относится к другим Libre/OOP-путям.
4. **No calibration** отключает применение поправки к новым значениям и скрывает пункт добавления калибровки. Сохранённые калибровки не удаляются; при повторном включении может снова использоваться последняя действующая калибровка текущего сенсора.
5. Оставьте **Use external Blukon algorithm** выключенным для этого сценария: эта сторонняя настройка также отключает калибровку Libre в xDrip.

### 7.2. Ввод значения

1. Дождитесь свежего стабильного показания в xDrip. Не используйте калибровку как средство исправить разрыв связи, прогрев, быстро меняющуюся глюкозу или сомнительное измерение.
2. Подготовьте глюкометр, вымойте и высушите руки, выполните измерение по инструкции прибора.
3. Откройте меню xDrip → **Добавить калибровку / Add Calibration**.
4. Введите значение **в тех единицах, которые выбраны в xDrip**. Например, `7,8` или `7.8` при ммоль/л; `140` при mg/dL. Не вводите `140`, если экран работает в ммоль/л.
5. Сохраните. Если приложение сообщает, что калибровка не создана, не считайте её принятой: проверьте наличие свежих данных, активной локальной записи сенсора, единицы и журнал.
6. Проверьте запись в графике/таблице калибровок и дождитесь **нового** показания. Самая надёжная проверка применения поправки — следующее новое значение, а не форма уже нарисованного участка истории.

### 7.3. Как работает поправка

Для источника `Libre2 Patched` калибровка имеет наклон `1` и ограниченное смещение:

```text
показание после калибровки = входное значение после сглаживания + смещение
смещение ограничено диапазоном −40…+20 mg/dL
```

Это примерно −2,2…+1,1 ммоль/л. Несколько калибровок участвуют в штатном алгоритме xDrip; новое значение с глюкометра не гарантирует точное совпадение каждой следующей точки с ним. При большом расхождении предел поправки не расширяется автоматически.

Пример расчёта, **не рекомендация для ввода**: вход `130 mg/dL`, глюкометр `140 mg/dL`, поправка `+10`. Следующая входная точка `140 mg/dL` отображается примерно как `150 mg/dL`. Сглаживание, границы отображаемой глюкозы и последующие калибровки могут влиять на результат.

История протокола вставляется по фактически переданным точкам, без spline-достраивания отсутствующих значений. Калибровка действует на новые вставляемые текущие и исторические значения. Штатный пересчёт недавних точек зависит от числа калибровок и настройки переписывания истории. Переключение в `No calibration` не отменяет уже сделанные изменения истории.

## 8. Тревоги, Nightscout и внешние приложения

1. После настройки приёма проверьте разрешение уведомлений, звук, громкость, режим «Не беспокоить» и ограничения батареи.
2. Настройте тревогу об отсутствии данных, а не только пороги высокой/низкой глюкозы. Проверяйте доступным приложению способом тестирования звука, а не намеренным изменением глюкозы.
3. После выключения экрана убедитесь, что поступают новые данные и уведомления работают. Отдельно повторите проверку после перезагрузки телефона.
4. Если выгружаете данные в Nightscout, определите один основной источник. Одновременная выгрузка из Juggluco и xDrip может создавать дубли и смешивать значения до и после калибровки.
5. Подключение AAPS и других систем настраивайте по их документации после проверки локального пути. Получатель должен брать именно нужный поток; иначе он может видеть исходную глюкозу из Juggluco вместо скорректированной из xDrip.
6. Это руководство не подтверждает пригодность сборки для автоматического управления инсулином. Такая интеграция требует отдельной проверки на устройстве.

## 9. Замена сенсора и обновление приложения

**Новый сенсор:** сначала добейтесь работы нового сенсора в Juggluco. Проверьте, что xDrip зарегистрировал новую сессию. Если мост не передал метаданные старта сенсора и xDrip продолжает старую сессию, завершите старую локальную сессию в xDrip и зарегистрируйте новую. Не переносите старую поправку на новый сенсор без проверки. Не нажимайте «Остановить сенсор» в приложении, непосредственно управляющем физическим сенсором, вместо завершения локальной записи xDrip.

**Обновление xDrip:** сначала резервная копия, затем APK с той же подписью. После обновления проверьте источник, единицы, калибровку, свежесть данных, тревоги и выгрузку. Самостоятельно собранный debug APK обычно имеет другую подпись, чем ранее полученный release APK.

## 10. Если что-то не работает

| Симптом | Что проверить по порядку |
|---|---|
| Нет новых значений в Juggluco | Поддержка модели/региона, прогрев, NFC-скан, разрешения, Bluetooth и конкурирующее подключение. До исправления xDrip не поможет |
| В Juggluco есть данные, в xDrip нет | `Patched Libre broadcast`; пакет `com.eveningoutpost.dexdrip`; источник `Libre2 Patched`; оба приложения открыты после установки/force-stop; один Android-профиль |
| В System Status меняется время, график обновляется реже | Минутный вход и более редкие сохранённые точки ожидаемы; проверьте сглаживание и интервал, не включайте сразу несколько способов приёма |
| Данные пропадают при погашенном экране | Фоновая работа/автозапуск обоих приложений, системная экономия батареи, принудительная остановка |
| Цифры отличаются от Juggluco ещё до калибровки | Временные метки, сглаживание xDrip, активная калибровка Juggluco и оставшаяся калибровка текущей сессии xDrip |
| Нет Add Calibration | Есть ли локальная активная сессия; включён ли режим калибровки; выключен ли external Blukon; завершены ли начальные экраны |
| Калибровка отклонена | Свежие показания, единицы, диапазон введённого значения, журнал; запись глюкометра сама по себе не доказывает принятие калибровки |
| В No calibration новые значения всё ещё с поправкой | Проверьте версию APK: старый `718d082` имел такой дефект на текущем потоке. Также проверьте активную калибровку Juggluco |
| Поправка меньше ожидаемой | Предел −40…+20 mg/dL, несколько калибровок в расчёте, сглаживание; не пытайтесь исправлять большую ошибку многократным вводом |
| NFC xDrip сообщает про Gen2 | Это ожидаемая подсказка: читайте сенсор Juggluco, принимайте данные источником `Libre2 Patched` |
| Не восстановилась история за разрыв | Patched Libre broadcast Juggluco — поток текущих значений; полный backfill этим каналом не обещан |
| APK не устанавливается поверх старого | Совпадение package ID не означает совпадения подписи. Сначала сохраните данные; порядок миграции — раздел 2 |

При обращении за помощью укажите Android/модель телефона, модель/регион сенсора, версии обоих APK, источник xDrip, время последнего значения в каждом приложении и выбранный режим калибровки. Скройте персональные данные в журналах.

## 11. Проверка готовности на реальном телефоне

- [ ] Juggluco принимает свежие значения по Bluetooth.
- [ ] xDrip получает новые точки без первоначальной калибровки.
- [ ] Единицы совпадают с ожидаемыми.
- [ ] Включённый режим показывает Add Calibration, запись сохраняется, новая точка использует поправку.
- [ ] В `No calibration` новая точка приходит без поправки xDrip; собственная поправка Juggluco выключена.
- [ ] При повторном включении режима поведение сохранённой калибровки понятно.
- [ ] Поток продолжается с выключенным экраном и после перезагрузки.
- [ ] Тревоги слышны, потеря потока обнаруживается.
- [ ] Внешние получатели берут нужный поток без дублей.
- [ ] При замене сенсора начинается новая локальная сессия без старой поправки.

Эти пункты нужно выполнить на вашем оборудовании. Отметки здесь намеренно не заполнены: облачная сборка не имеет телефона и сенсора.
